# PLX-4 Annotation Kit

Human quality scoring tooling used during the PLX-4 corpus audit.

- `annotations/quality_scores.jsonl` - per-document human quality scores (`doc_uid`, `score`)
- `annotation_guide.md` - label definitions and scoring rubric

The kit covers annotation tooling and human scores only. Corpus text is not
redistributed in this repository and no corpus bytes are hosted here.
